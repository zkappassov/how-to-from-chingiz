# Factorial Recursive

A simple Python script that computes the factorial of a non-negative integer using recursion.

## Files

- `factorial_recursive.py` - Recursive factorial implementation with command-line interface.

## Usage

Run the script with a non-negative integer argument:

```bash
python factorial_recursive.py 5
```

Expected output:

```bash
120
```

## Notes

- Raises `ValueError` for negative integers.
- Supports 0 and 1 as valid inputs.
